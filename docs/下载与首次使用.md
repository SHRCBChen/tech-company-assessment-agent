# WorkBuddy下载与首次使用

## 一、下载哪个文件

同事首次使用时，请下载完整工作流，不要只下载Skill：

- 完整工作流（推荐）：<https://github.com/SHRCBChen/tech-company-assessment-agent/archive/refs/heads/main.zip>
- WorkBuddy专用完整包：<https://github.com/SHRCBChen/tech-company-assessment-agent/raw/refs/heads/main/packages/workbuddy-complete-package.zip>
- 仅WorkBuddy Skill：<https://github.com/SHRCBChen/tech-company-assessment-agent/raw/refs/heads/main/packages/workbuddy-skill.zip>

完整工作流包含Skill、使用说明、输入示例、首次任务提示词、数据结构和生成脚本。仅Skill包只适用于已经拥有同一套完整工作流文件的电脑，不能单独完成批次建立和成果生成。

公开仓库无需GitHub账号。打开第一个链接会直接下载压缩包；也可以进入仓库主页，选择`Code → Download ZIP`：

<https://github.com/SHRCBChen/tech-company-assessment-agent>

## 二、解压和安装

1. 将完整工作流解压到固定文件夹，例如`D:\企业尽调Agent`。不要放在微信临时目录。
2. 在该文件夹空白处按住Shift并单击鼠标右键，选择“在终端中打开”。
3. 在PowerShell中只复制命令本身，不要复制提示符、报错信息或`PS C:\...>`：

```powershell
python -m pip install -r requirements.txt
python .\scripts\check_installation.py
```

看到`INSTALLATION_OK`后再继续。如果当前终端不在工具目录，PowerShell应使用：

```powershell
Set-Location -LiteralPath "D:\企业尽调Agent"
```

不要在PowerShell中使用CMD格式的`cd /d`。

## 三、导入WorkBuddy Skill和连接器

1. 在WorkBuddy中进入“技能”，上传`packages\workbuddy-skill.zip`并启用。
2. 在“管理连接器”中启用官方企查查连接器并完成登录授权。
3. 如需自动更新知识库，再启用单位允许使用的ima连接器，并确认账号有目标知识库的编辑权限。
4. 企查查或ima连接器未启用、授权失效、触发验证码或字段不可用时，应先修复连接器，不得让模型降低检索标准。

## 四、开始第一批任务

企业名单和现场笔记不要求放在同一个文件：

- 企业名单：Excel或CSV，至少有一列企业名称或项目名称；
- 现场笔记：可以是独立Excel/CSV、Word、图片或PDF，也可以一次上传多个附件。

把名单、笔记、单位确认版推进意见模板和`workbuddy\首次任务提示词.txt`交给WorkBuddy。首次任务提示词中的文件名和批次名称替换为实际名称。示例文件位于`examples`目录。公开包不附带含真实企业内容的推进意见样稿，避免内部材料进入公开仓库。

完整说明见：`docs\WorkBuddy使用说明.md`。

## 五、四件交付成果

每批应交付：

1. 企业信息主表Excel；
2. 一家企业一条可编辑ima当前事实底稿；
3. 1—2页企业初评报告；
4. 严格按模板生成的推进意见。

四件成果由同一批次的事实记录生成。Excel、报告或ima笔记中的手工改动不会自动回写事实记录；拜访后更新时，应先把增量材料写回原批次事实记录，再重建四件成果。

## 六、交接时不要发送的内容

不要把企业名单、现场笔记、运行目录、报告、API Key、ima Client ID、`.secure`文件夹或`config\ima.json`放进公开GitHub仓库。完整工作流压缩包只包含可复用工具，不包含本次25家企业资料。
